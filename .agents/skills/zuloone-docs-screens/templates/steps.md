# Разбор `steps.json`

JSON комментариев не держит, а поля-`_comment` засоряют файл, который читают
три потребителя. Поэтому пояснения живут здесь, рядом.

Файл-пример — сценарий «Завести товар». Кладётся в
`wiki/learn/steps/<сценарий>.json`, имя файла = значение `scenario`.

> **Ещё не сделано** (волна 1 плана
> `docs/superpowers/plans/2026-09-23-documentation-and-training.md`): контракт
> манифеста (`wiki/learn/steps/_schema.md`) и его исполнитель
> (`frontend/e2e/docshots.spec.ts`) не написаны. Пример ниже — предложение
> формы, а не описание работающего файла: поля минимальны намеренно, чтобы
> контракт можно было расширять, не ломая уже написанные сценарии.

## Шапка файла

| Поле | Обязательно | Что значит |
|---|---|---|
| `scenario` | да | идентификатор, он же имя файла; kebab-case, латиница |
| `title` | да | как сценарий называется в уроке и в туре |
| `owner` | да | страница, которая его рендерит. Осиротевший манифест — кандидат на удаление, а не «пусть полежит» |
| `defaults.locale` | нет | умолчание `ru`; переопределяется на шаге |
| `defaults.theme` | нет | умолчание `light`; переопределяется на шаге |

## Шаг

| Поле | Обязательно | Что значит |
|---|---|---|
| `id` | да | якорь шага. По нему ссылается урок и подсвечивает тур; менять = ломать ссылки |
| `title` | да | строка нумерованного списка в доке. Повелительное наклонение, подписи интерфейса — **жирным**, дословно |
| `route` | одно из | прямой маршрут (`/dictionaries`, `/scripts`) — короче и надёжнее хождения по ленте |
| `ribbon` + `menu` | одно из | путь по ленте, когда прямого маршрута нет |
| `actions[]` | нет | что сделать на экране ДО снимка; пустой массив = снять как есть |
| `shot` | нет | снимок этого шага; без него шаг остаётся текстовым |
| `note` | да, если есть `shot` | подпись под картинкой: что на ней надо увидеть |

Шаг без `route` и без `ribbon`+`menu` продолжает экран предыдущего — так
описывается последовательность действий на одной форме.

## `actions[]`

Действие — объект с ключом `do` и параметрами под него:

| `do` | Параметры | Зачем |
|---|---|---|
| `click` | `role`, `name` — либо `selector` | нажать кнопку. Адресация по роли и подписи переживает вёрстку; `selector` — только когда у элемента нет доступного имени, и тогда в `note` пишется, почему |
| `dblclick` | то же | открыть строку списка карточкой |
| `fill` | `label`, `value` | ввести значение в поле по подписи |
| `pickReference` | `label`, `value` | выбрать из связанного справочника: набрать и подтвердить, а не кликать по выпадашке |
| `wait` | `ms` | пауза, когда экран доезжает асинхронно |
| `expectRows` | `atLeast` | **утверждение, а не ожидание**: пустой снимок хуже отсутствующего, потому что он едет в прод |
| `tableView` | — | переключить справочник с плиток на таблицу (у справочников с картинкой плитки рисуют стену битых глифов) |
| `blur` | — | снять фокус: `Select` в фокусе показывает placeholder вместо значения |

`blur` и парковка мыши делаются конвейером автоматически перед каждым снимком —
в `actions[]` он нужен только там, где фокус надо снять раньше, до других
действий.

## `shot`

| Поле | Значения | Что значит |
|---|---|---|
| `name` | `<тема>-<что>` | имя файла без расширения. Латиница, kebab-case, без дат |
| `of` | `page` \| `selector` | весь экран или один элемент. Умолчание — `page`: читателю надо опознать форму, а не поле |
| `selector` | CSS | обязателен при `of: "selector"` |
| `locale` | `ru` \| `en` \| `uk` \| `ar` \| `all` | умолчание из `defaults`. `all` — только на экраны, попадающие в переведённые уроки: вчетверо больше файлов протухают вчетверо чаще |
| `theme` | `light` \| `dark` | умолчание из `defaults`. Тёмный — отдельный снимок, а не замена светлого |

Имя файла **одно на все локали и темы**: суффикс добавляет конвейер, а текст
страницы ссылается на базовое имя и получает нужный вариант.

## Что важно в примере

- **Ленту проходим по английским подписям** (`ribbon: "Inventory"`,
  `menu: "Items"`): вкладки резолвятся из живого `/api/metadata/menu` по
  `caption.en`, а подписи пунктов переводятся на клиенте — после включения
  арабского «Items» как подписи не существует. Локаль переключается уже на
  нужном экране, перед снимком.
- **Шаг `fill-header` помечен `locale: "all"`** — это единственный кадр
  сценария, попадающий в переведённые уроки; остальные снимаются только на ru.
- **Шаг `save` снимает `selector`, а не страницу**: доказать надо появление
  номера в шапке, а не перерисовать ту же форму третий раз.
- **Шаг `back-to-list` содержит `expectRows: 11`** — это и есть самопроверка
  урока, выраженная кодом: на одну строку больше, чем было на первом шаге.
